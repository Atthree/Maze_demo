# Maze Demo

![Unity](https://img.shields.io/badge/Unity-000000?logo=unity&logoColor=white)
![C#](https://img.shields.io/badge/C%23-512BD4?logo=csharp&logoColor=white)

A Unity 2D maze game for Android. It uses a virtual joystick and touch controls (SimpleInput).

## Features

- Touch and virtual joystick controls
- Built for Android devices

## How to run

1. Clone the repository: `git clone https://github.com/Atthree/Maze_demo.git`
2. Open the project folder with Unity Hub.
3. Open the scene in `Assets` and press **Play**, or build for Android from **File > Build Settings**.
